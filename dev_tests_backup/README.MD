# dev_tests_backup

Архив тестов, которые использовались во время разработки покрытия (вплоть до 100%).

Эта папка не участвует в pytest по умолчанию (лежит вне `tests/`).

Если нужно временно вернуть тесты:
- перемести нужные файлы обратно в `tests/`
- запусти `pytest -q` 
- or `pytest --cov=apps --cov=config --cov-report=term-missing`
